
متابعة التجارب الحقلية 🍓
تطبيق ويب بسيط (PWA) لمتابعة التجارب الحقلية عند العملاء: تسجيل العملاء والزيارات أوفلاين في الأرض، وتسجيل اللوكيشن بالـ GPS، والتصوير، وبعد كده المزامنة مع Google Sheets ورفع الصور على Google Drive. كل عميل له فولدر خاص بيه وملف Google Docs فيه رحلته كاملة.

المميزات
أوفلاين بالكامل: يتسجل كل حاجة على الموبايل من غير نت، والبيانات بتتحفظ على الجهاز (IndexedDB).
اللوكيشن بالـ GPS (يشتغل أوفلاين) لكل عميل ولكل زيارة، مع رابط Google Maps.
المتابعة (Follow-up): التطبيق يحسب مواعيد الزيارات تلقائياً (مثلاً يونايت ← بعد 7 أيام أجري كيور ← بعد 7 أيام متابعة نهائية)، ويعرض المتأخر والمستحق النهارده والقادم خلال أسبوع، مع أزرار اتصال وواتساب وخريطة.
تسجيل حر: المناطق مش متحددة، تكتب أي منطقة أو مركز أو قرية. فيه "حقول إضافية" لأي بيانات زيادة، والزيارات والمنتجات بتتعدل من الإعدادات.
مزامنة تلقائية دايماً: البيانات بتترفع بعد كل حفظ، وكل كام دقيقة (بتتظبط من الإعدادات)، وأول ما النت يرجع، ولما تفتح التطبيق.
الصور: بتتضغط وبتتحفظ على الجهاز، وبتترفع تلقائياً في الخلفية أول ما يبقى فيه نت. وفيه اختيار للرفع على الواي فاي بس، وزرار رفع يدوي في أي وقت.
Google Drive: فولدر لكل منطقة، وجواه فولدر لكل عميل، وجواه فولدرات الزيارات مترتبة:
متابعة التجارب - ملفات العملاء/
  └─ القليوبية/
      └─ QL-001 - محمد عبد الله - الدير - القليوبية/
          ├─ 01 - زيارة 1 - يونايت/        (الصور)
          ├─ 02 - زيارة 2 - أجري كيور/
          ├─ 03 - زيارة 3 - متابعة نهائية/
          └─ ملف العميل - QL-001 ... (Google Doc)
Google Sheets: فيه 3 شيتات (العملاء، الزيارات، الصور)، وتقدر تفتحهم أوفلاين أو تصدّرهم Excel.
ملف Docs لكل عميل: فيه بياناته وكل زيارة بقراءاتها وصورها، وبيتحدث تلقائياً.
تصدير Excel وCSV ونسخة احتياطية JSON من التطبيق نفسه، حتى من غير نت. وفيه استيراد قائمة عملاء من CSV.
تصميم عصري عربي (RTL) بيدعم الوضع الغامق، ويتثبت على الموبايل كتطبيق (Add to Home Screen).
أكتر من جهاز: كل الفريق يقدر يستخدم نفس الرابط، والمزامنة بتسحب تحديثات الباقيين.
خطوات التشغيل
1) استضافة التطبيق على GitHub Pages
ارفع الملفات دي على ريبو في GitHub (أو استخدم الريبو ده).
من الريبو افتح Settings ← Pages.
في Source اختار Deploy from a branch، والبرانش main، والفولدر / (root)، وبعدين Save.
بعد دقيقة هيكون التطبيق شغال على: https://<اسم-المستخدم>.github.io/<اسم-الريبو>/
افتح الرابط من موبايل كل فرد في الفريق، ومن قائمة المتصفح اختار Add to Home screen / إضافة للشاشة الرئيسية.
لازم تفتح التطبيق مرة واحدة وانت متصل بالنت، وبعدها يشتغل أوفلاين.

2) ربط Google Sheets + Drive + Docs (مرة واحدة، 5 دقايق)
اعمل Google Sheet جديد وسمّيه مثلاً "متابعة التجارب".
من القائمة Extensions ← Apps Script.
امسح الكود الموجود، والصق محتوى الملف apps-script/Code.gs.
غيّر السطر const TOKEN = 'CHANGE-ME-123'; لكلمة سر خاصة بيك.
اختار الدالة setup من فوق واضغط Run، ووافق على الصلاحيات. الشيتات وفولدر العملاء هيتعملوا.
اضغط Deploy ← New deployment، واختار النوع Web app، وظبط:
Execute as: Me
Who has access: Anyone
وبعدين اضغط Deploy وانسخ Web app URL.
في التطبيق افتح الإعدادات، وحط الرابط والـ TOKEN، واضغط اختبار الاتصال وبعدين حفظ.
لو عدّلت الكود بعد كده: Deploy ← Manage deployments ← Edit ← Version: New version، والرابط هيفضل زي ما هو. لو حسابك Google Workspace تابع لشركة، ممكن الأدمن يكون قافل اختيار "Anyone". ساعتها استخدم حساب Gmail عادي.

3) الوصول أوفلاين للشيت والملفات
Google Sheets / Docs: من Google Drive فعّل Settings ← Offline، وعلى الموبايل اختار "Make available offline" للشيت أو للملف.
أو من التطبيق: المزامنة ← Excel وهينزل ملف فيه كل العملاء والزيارات.
ربط كل الأجهزة تلقائياً + حماية الإعدادات (مرة واحدة من الأدمن)
في Apps Script غيّر السطرين دول، وبعدين اعمل Deploy ← Manage deployments ← ✏️ ← New version:
const TOKEN = 'كلمة-سر-الربط';
const ADMIN_PASSWORD = 'كلمة-سر-الأدمن';
على GitHub افتح config.js ← ✏️ وحط:
apiUrl: رابط الـ Web App (آخره /exec)
token: نفس TOKEN اللي في Apps Script
افتح التطبيق ← الإعدادات ← في آخر الصفحة اكتب كلمة سر الأدمن (نفس ADMIN_PASSWORD) ← توليد، وانسخ السطر adminPasswordHash: '…' وحطه في config.js.
اعمل Commit. من اللحظة دي:
أي جهاز (حتى الجديد) يفتح الرابط بيتربط ويرفع على جوجل لوحده، ويطلب بس اسم المستخدم أول مرة.
صفحة الإعدادات وحذف العملاء أو الزيارات محتاجين كلمة سر الأدمن.
أي تغيير يعمله الأدمن في الإعدادات (الزيارات، المنتجات، المناطق، المزامنة) بيوصل لكل الأجهزة في أول مزامنة.
⚠️ الريبو عام، فأي حد يقدر يقرا config.js ويشوف رابط الربط والـ TOKEN. ده بيسمح بالكتابة في الشيت لو حد قصد ده، لكن مش بيسمح بقراية الصور أو الملفات. لو البيانات حساسة، خلي الريبو Private (GitHub Pages للريبو الخاص محتاج اشتراك GitHub Pro).

الاستخدام اليومي
في الأرض (أوفلاين عادي): من شاشة اليوم هتلاقي الزيارات المستحقة. دوس تنفيذ الزيارة، واللوكيشن هيتسجل تلقائي. سجّل القراءات وصوّر واحفظ.
عميل جديد: من زرار +.
المزامنة: بتحصل لوحدها. ولو عايز ترفع حالاً، من المزامنة دوس مزامنة الآن أو رفع الصور.
المتابعة: افتح ملف أي عميل وهتلاقي رحلته وروابط فولدر الدرايف وملف Docs بتاعه.
ضبط التجربة
من الإعدادات ← زيارات الرحلة، سطر لكل زيارة بالشكل ده:

زيارة 1 - يونايت | 0 | يونايت
زيارة 2 - أجري كيور | 7 | أجري كيور
زيارة 3 - متابعة نهائية | 14 |
(الاسم | بعد كام يوم من بداية التجربة | المنتج). ولو زيارة اتأخرت، المواعيد اللي بعدها بتتحسب من تاريخها الفعلي.

الملفات
الملف	الوظيفة
index.html, app.css, app.js	التطبيق
config.js	الربط لكل الأجهزة + بصمة كلمة سر الأدمن
sw.js, manifest.webmanifest	التشغيل أوفلاين والتثبيت كتطبيق
apps-script/Code.gs	الربط مع Sheets وDrive وDocs (بيتلصق في Apps Script)
الخصوصية
بيانات العملاء مش محفوظة في الريبو. هي محفوظة على أجهزة الفريق وفي حساب Google بتاعك بس. رابط الربط والـ TOKEN بيتكتبوا في إعدادات كل جهاز ومش موجودين في الكود.
