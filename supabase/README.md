# قاعدة البيانات (Supabase)

المشروع: `field-trials` على Supabase (الخطة المجانية).

- الجداول (`clients`, `visits`, `photos`, `app_config`) مقفولة بالكامل (RLS من غير policies). محدش يقدر يقراها أو يكتب فيها مباشرة.
- **`ft_api(action, token, payload)`**: الدالة الوحيدة اللي التطبيق بيكلمها، وبتتأكد من رمز الفريق قبل أي عملية.
- **`ft_bridge(action, key, payload)`**: بيستخدمها Apps Script كل 5 دقايق بمفتاح خاص، علشان ينقل البيانات للشيت والصور للدرايف. بعد نقل كل صورة بتتمسح من السحابة، فالمساحة المجانية مابتخلصش.
- الأسرار (رمز الفريق، بصمة كلمة سر الأدمن، مفتاح الربط) محفوظة في `private.secrets`، ومش موجودة في الريبو.
